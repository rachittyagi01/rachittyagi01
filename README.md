## 👤 About Me

I'm a Computer Science and Engineering graduate with a strong interest in full-stack web development and problem solving. I primarily work with the **MERN stack** — building RESTful APIs, integrating authentication and authorization, managing application state, and shipping features from database to UI.

I enjoy turning ideas into working products, with hands-on experience in testing, third-party service integration, and deploying full applications end-to-end.
